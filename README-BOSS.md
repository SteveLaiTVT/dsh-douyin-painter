# 弹幕画师 · 老板模式

**当前沙箱交付包未捆绑 runtime/node，需 Mac 已安装 Node.js 24；下载受阻，尚不满足“自带运行时、解压即跑”验收。** 配套源码可补入官方运行时后重打包。没有放入占位程序。

1. 解压 `danmu-painter-mac.zip`，进入 `danmu-painter-mac` 文件夹（请放在本机可写目录）。
2. 双击 **启动.command**，约 1 秒后打开控制页；首次被 macOS 拦截时，在访达右键选择「打开」。
3. 在控制页「设置」填 **OpenAI API Key** 和 **单场预算 USD**（默认 **5**），点「保存设置」。没有 Key 也可直接演示：**MOCK 演示**，不请求 OpenAI。Key 留空保留旧值，用「清除已保存的 Key」删除。
4. 点击 **开新轮**。默认关闭 douyinLive：在控制页 **手动代录** 区输入 `画：月亮上的小猫`，提交后逐条「通过，加入候选」。要接入真实弹幕，先运行本机 douyinLive，在设置填直播间标识并打开开关。
5. 停收前可修改候选分数与理由，再点「停收并提交全量评分」，**10 秒内**确认榜单。默认同分、先收到者优先，属于主播评选。揭榜 12 秒后自动出图；静图 10 秒、GIF 15 秒终审，通过才可上屏，GIF 必须逐帧检查且看完一圈。
6. 点击「打开舞台页」，首次连接或重连后点 **确认并上屏已审画面**。直播伴侣只采集舞台；舞台常驻 **AI 生成内容**，演示图另有明显 **MOCK 演示** 标注。输出违规点「拒绝」，整轮立即撤播；临时切画面用「紧急遮罩」。

控制页：<http://127.0.0.1:7321/control>　舞台页：<http://127.0.0.1:7321/stage>。

**关闭启动器的终端窗口即停服**，也可按 Ctrl+C；关浏览器不会停服。再次启动为新一场，历史保留在 `data/runtime/`，当前场累计预算不会因开新轮重置。一个场次最多 9 次图片请求（包含重试和 MOCK）。

**Key 明文存于本机 `data/settings.json`**（权限 600），不使用 `.env` 或登录令牌。预算和弹幕接入保存即生效，Key 在下一轮生效，无需重启，旧轮 MOCK 标注保持不变。设置文件不要公开或转发。真实请求每次先预留 $1，费用待账单核对；MOCK 为 $0，预算设为 0 可停止付费请求。真实 API、macOS 首启和直播伴侣采集尚待现场确认。
