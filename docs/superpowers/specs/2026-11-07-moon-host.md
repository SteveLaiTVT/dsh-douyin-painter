# 月球摊主动画

用户已批准在现有舞台加入 LivLiv 人物动画并在验收后分组提交、push。本次直接执行，不再开启设计问答。

采用 @livliv-dev/player 0.3.0 的 BodyPlayer、自定义 Canvas 角色与 startLipSync。原创小机器人阿月穿围裙、戴月球头盔；由代码绘制，保留以后更换 LivLiv/VRM/PNGTuber 的接口边界。相比下载精选人物，此方案无第三方角色再分发限制；相比远程 iframe，能够复用当前 MiniMax 流式 audio，不创建第二个播放器。

舞台底部内容区独立一行，保持左右 112px 和底部 230px 安全区。待机呼吸眨眼、播音嘴型、候选点头、作品揭晓微笑轻跳。启动和历史回看不重复庆祝。字幕只显示当前真实播音，暂停/关闭声音立即闭嘴。控制板提供持久化显示开关。动画或模块失败不阻止原有比赛和语音。无摄像头、无额外 AI 请求或外部网络运行依赖。

验收：本机静态模块可访问；控制开关重启保留；真实浏览器 MP3 尚未结束生成即播放且嘴型变化；静音/结束闭嘴；不同竖屏尺寸不越出安全区，不遮挡作品。保留代码与真实直播捕获验证的区别。
