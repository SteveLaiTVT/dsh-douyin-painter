# 主题策划与人工 Review

用户要求给一个主题，由 DeepSeek 生成完整故事板、类型与题材，再由主播 Review。延续已有 localhost 控制台与 DeepSeek 非思考接口，直接实现已授权的准备流程。

选择在主题设置之上新增独立策划区。用户已明确选择三个不同题材方向，各有标题、题材类型、故事钩子、世界背景、视觉风格、观众参与引导、规则、三个创意示例、开场词、生图指导及3–5格故事板。每格包含名称、画面、动作、主持词。一个完整方案反复改稿也可实现，但默认三个方向方便比较；不采用自动发布，以保证用户 Review。

生成只保存草案，不改变主题、赛程、作品或音频。选中方向后所有内容均可编辑、保存，再显式应用；活动轮次不允许切换主题，避免清空当前观众投稿。草案可在直播中准备并跨重启保留。重复生成不自动重试，失败保留旧草案。

采用方案后保存批准内容，接话/评选/规则解说与生图共同读取。已审核的世界背景替代旧的月球场景硬编码；观众明确风格和道具辨识仍优先。策划示例不是实际观众发言。故事板组织整场叙事，单个1.2秒GIF只选一镜轻动作，不承诺生成多镜头视频。

草案生成独立于轮次重置；应用和保存须匹配草案ID，拒绝旧页面覆盖新方案。可选草案损坏时不清空比赛记录。新能力同时支持 API 与 Harness 文本适配。
